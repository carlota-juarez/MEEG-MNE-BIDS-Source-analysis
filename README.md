## At a glance

<!-- brainlife-app:begin (generated from the App manifest; edit the manifest, not this block) -->

> **Runs the source-level steps of MNE-BIDS-Pipeline on sensor-level M/EEG BIDS derivatives: head model (FreeSurfer recon-all or the fsaverage template), BEM, source space, forward and inverse solutions (dSPM, MNE, sLORETA or eLORETA) and HTML reports.**

Third App of the MNE-BIDS-Pipeline series: takes the BIDS derivatives produced by the Sensor Analysis App, writes an MNE-BIDS-Pipeline configuration from the App parameters and runs the freesurfer and source steps. With a T1w and no template MRI it runs FreeSurfer recon-all (needs a FreeSurfer license, which can be pasted in fs_license); otherwise it uses a template MRI such as fsaverage. Source estimation is skipped for resting-state recordings without evoked data. Use it after the Sensor Analysis App to estimate cortical sources of evoked M/EEG responses.

#### Inputs

| Input | Datatype | Required | Description |
|---|---|---|---|
| `bids_dir1` | `raw` (mne, sensor) | yes | The sensor M/EEG data structure in BIDS format, generated by the MNE-BIDS-Pipeline [2]: Sensor Analysis App. This input must contain the sensor derivatives for exactly one subject and a single run. Select the data object generated in the previous step (tagged with 'mne' and 'sensor'). |
| `t1` | `neuro/anat/t1w` | no | Optional T1-weighted structural MRI scan of the subject. Provide this file if you want to perform source estimation using the subject's actual anatomy. The App will automatically run FreeSurfer's 'recon-all' pipeline. A valid FreeSurfer license string in the App configuration parameters is required if you use the T1w. If omitted, you can configure the App to use a standard template anatomy. |

#### Outputs

| Output | Datatype | Description |
|---|---|---|
| `out_dir` | `raw` | Copy of the input BIDS derivatives plus the source-level outputs (BEM, source space, forward, inverse and source estimates). |
| `html_report` | `report/html` | MNE-BIDS-Pipeline HTML reports of the source-level analysis. |

## Running the App

### On brainlife.io

Open the App at [doi.org/10.25663/brainlife.app.942](https://doi.org/10.25663/brainlife.app.942), choose `raw`, `neuro/anat/t1w` from your project, set the parameters and press **Execute**. The results are saved to your project as `raw`, `report/html`.

### Locally

You need [Singularity/Apptainer](https://apptainer.org/) (the App runs in `ghcr.io/carlota-juarez/app-mne-bids@sha256:c1fc17be21bbfda1e15de3fd1a6b8d42329204d6ec26e277a9cd5568cb1ebacd`), [`jq`](https://jqlang.github.io/jq/), `FS_LICENSE`.

1. Clone this repository.
2. Create `config.json` with the paths to your inputs and the parameters:

   ```json
   {
       "bids_dir": "/path/to/bids_dir1/bids_dir",
       "t1": "/path/to/t1/t1",
       "data_type": "",
       "eeg_template_montage": "standard_1020",
       "meg_ch_types": "meg",
       "task_is_rest": false,
       "task": "",
       "conditions": "",
       "interactive": false,
       "run_source_estimation": true,
       "fs_license": "",
       "subjects_dir": "",
       "use_template_mri": "fsaverage",
       "adjust_coreg": false,
       "bem_mri_images": "auto",
       "recreate_bem": false,
       "recreate_scalp_surface": false,
       "freesurfer_verbose": false,
       "mri_t1_path_generator": "",
       "mri_landmarks_kind": "",
       "spacing": "oct6",
       "mindset": 5,
       "loose": 0.2,
       "depth": 0.8,
       "inverse_method": "dSPM",
       "noise_cov": "",
       "noise_cov_method": "shrunk",
       "cov_rank": "info",
       "source_info_path_update": "",
       "inverse_targets": "['evoked']"
   }
   ```

3. Run `./main`.

## Troubleshooting

- **A T1w MRI is required to run recon-all. Provide it via the 't1' parameter or set 'use_template_mri' to 'fsaverage' to skip recon-all.**: Connect a T1w input or set use_template_mri to fsaverage.
- **No FreeSurfer license available. Provide one in 'fs_license'**: Paste the FreeSurfer license in fs_license or use a template MRI.
